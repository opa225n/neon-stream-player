# Neon Stream Player

Lecteur IPTV moderne (HTML + Tailwind CSS).

## Utilisation

Ouvre `index.html` dans un navigateur ou déploie sur Netlify/Vercel.

## Fonctionnalités

- Import de playlist M3U (URL ou fichier)
- Détection automatique des catégories (TV, Films, Séries, Sport)
- Lecteur HLS
- Interface dark premium
